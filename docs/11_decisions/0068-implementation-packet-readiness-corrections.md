# ADR-0068: Implementation Packet Readiness Corrections
status: ACCEPTED

> **AMENDMENT NOTICE (ADR-0072)**: item 1 two-phase list includes `IMP-083`, and a `-done` PR may carry fixes inside the packet's `owned_paths`; item 5 GUIDs are editor-generated (CI materialization) except the path-derived ProjectSettings baseline references.

## Context
The round-2 AI-readiness review of `../10_implementation/task_queue.md` found packets that could never finish: two-phase tasks cited a "post-merge `main` run" of `verify.yml` that no workflow produces; gate skipping was tied to Bootstrap Mode while several gate owners finish after `IMP-068`; geometry export was owned by a task without scenes; travel, currency and PUBLIC boss scheduling were implemented by packets outside the owning dependency chain; Unity ProjectSettings and assembly references were frozen at `IMP-000`; and Q6 evidence identity had no test owner.

## Decision
1. **Two-phase evidence**: the follow-up status PR of a two-phase gate task commits the `evidence` artifact of its own `verify.yml` run. This is valid because `source_tree_hash` excludes `task_queue.md` and `evidence/**`, so the status PR's tree hash equals the merged implementation tree. The post-merge guard (`post_merge_guard.yml`) never produces task evidence. Amends ADR-0057 item 6.
2. **Gate activation**: a Q gate or sub-gate is required iff its owner task is `DONE` on `main` or set to `DONE` in the PR head; before that it reports `SKIP(owner-not-done)`, which is not a failure, before and after `IMP-068`. Bootstrap Mode only means PR-head verifier and empty ratchet. `IMP-068` exit requires every gate whose owner is `DONE` to run without skip. Amends ADR-0057 item 2.
3. **Geometry ownership**: `IMP-062` owns one collision-only authoring scene per playable space (`client/Assets/Scenes/Collision/<space_id>.unity`, colliders tagged `ServerGeometry`, anchors and bounds from the catalogs, no art), the exporter `ThinhThan.Core.Geometry.Editor.GeometryExporter`, every `server/internal/sim/spatial/maps/<space_id>.geom.json`, parity and golden vectors. Visual scenes of `IMP-072`/`IMP-105` carry no `ServerGeometry` colliders and align to the collision scenes. `IMP-018` depends on `IMP-062`. Gameplay never waits for final art, and layer/milestone order is preserved.
4. **Dependency corrections**: `NPC_SERVICE travel` moves from `IMP-018` to `IMP-020` (discovery owner, transitively after `IMP-007`); `IMP-018` owns the `NPC_SERVICE` dispatcher and `set_checkpoint`. `IMP-009` depends on `IMP-007`. `IMP-022` owns `server/internal/global/bosses/` for the PUBLIC generation lifecycle and depends on `IMP-080`; the `public_boss_schedules` migration stays with `IMP-005`; Edge admission is wired to the `WorldConsequence` recovery readiness signal by `IMP-069`. `IMP-036` receives guild EXP/Ritual/Gathering input only through the typed `guild.EventSink` and checks disband against `guild.WarRegistrationGuard`; producers (`IMP-022`, `IMP-023`, `IMP-025`, `IMP-059`, `IMP-042`) are wired to them by `IMP-069`.
5. **Unity project baseline**: `IMP-000` authors all mandatory `.asmdef` files with the reference graph of `../10_implementation/repository_layout.md` § Mandatory Assemblies, and pre-declares the ProjectSettings entries later packets need (`EditorBuildSettings` config objects for Addressables and Localization, `GraphicsSettings` URP asset slot, `TagManager` tag `ServerGeometry`) with GUIDs derived from the target asset path, so no later packet edits `client/ProjectSettings/` except `QualitySettings.asset` (`IMP-095`).
6. **Q6 and CI ownership**: `IMP-000` owns and tests evidence identity (`source_tree_hash`, manifest schema, `evidence manifest` job, API check of `ci_run_id` + `run_attempt`), the Q0-only fast path for status-only PRs, the PR role derived from the branch prefix, and the Linux xvfb/llvmpipe Unity step with the `visual-review` artifact upload.
7. **CLI install sources**: CI installs `pwsh`, `gh` and `jq` from the pinned GitHub release assets with SHA-256 verification; preinstalled runner copies are never used.

- Amends ADR-0057 items 2 and 6, and ADR-0046 item 6 (geometry exported from collision-only scenes).
